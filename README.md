# Save Money

Application de bureau pour suivre ses revenus, ses dépenses et son épargne, mois par mois.

- Revenus, dépenses ponctuelles et récurrentes
- Comptes d'épargne multiples, versements et retraits
- Courbe d'évolution sur 6 mois
- Données stockées localement sur ton ordinateur

## Télécharger

Rends-toi sur la page [Releases](../../releases) et télécharge la dernière version :

- **Installateur Windows** (`.msi` ou `.exe`) : lance-le et suis les étapes.

### Avertissement de Windows

L'application n'est pas encore signée par un éditeur reconnu. Windows SmartScreen peut afficher
« Windows a protégé votre ordinateur ». Pour continuer, clique sur **Informations complémentaires**,
puis **Exécuter quand même**.

Télécharge uniquement depuis cette page.

## Configuration requise

- Windows 10 ou 11 (64 bits)
- WebView2 (déjà installé sur Windows 11 ; sinon, l'installateur le propose)

## Mises à jour

Chaque nouvelle version est publiée dans [Releases](../../releases). Installe-la par-dessus
l'ancienne version, ou désinstalle l'ancienne avant si l'installateur le demande.
